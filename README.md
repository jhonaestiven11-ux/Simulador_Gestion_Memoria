# Simulador de Gestión de Memoria

Proyecto académico para simular la asignación de memoria mediante el algoritmo Best Fit (Mejor Ajuste).

## Características

- Particiones fijas.
- Asignación usando Best Fit.
- Cálculo de fragmentación interna.
- Visualización del estado de las particiones.

## Tecnologías

- HTML
- CSS
- JavaScript
